fault-affinity live reference kit

This small, experimental kit is mainly for Windows users who want to compare a pinned Node/PGlite workload by temporarily booting the real computer into Ubuntu. Existing Linux users can run the harness directly.

Use only a stable kit shown on the Releases page. If no stable release is listed yet, please wait rather than using a development snapshot.

Download

After choosing Try Ubuntu, open Terminal with Ctrl+Alt+T. Save the bootstrap first. Do not pipe a network response into a shell. 

wget -qO fault-affinity-run https://gadicc.github.io/fault-affinity/run
less fault-affinity-run
bash fault-affinity-run

The bootstrap resolves one exact GitHub Release, verifies its SHA-256, inspects every archive entry, and extracts it to a new directory. It never starts the live workload. You can inspect it first with less fault-affinity-run; press q to return to Terminal before running the final command.

When extraction finishes, copy the safe-preview command it prints. That command only shows the fixed case-study plan; it does not discover a suspect CPU. Read the storage and safety guide before using the separate --yes confirmation.

A live fault-reproduction workload can expose instability. Close other applications, choose how results will leave the live session, and read the supplied safety plan before choosing the separate --yes step. Never run the kit with sudo.
